Independent

3D Video Game First:

3D Video Game is a 3D game developed independently in Unity. The Player can attack enemies with sword attack, fireball attack, pick up items and explore the game environments. The game includes two enemy types: a fire enemy that attacks the player by shooting fireballs, and a sword enemy that follows that follows and attacks the player when they are detected. It also features checkpoint, platforms, loot blocks and other gameplay elements.

Module: 3D Game Programming

Techologies Skills:
  • GitHub
  • Unity
  • C#
  • Visual Studio
Features:
  • Sword combat
  • Jumping
  • Enemy AI
  • Fireball attacks
  • Pickup
  • Checkpoints
  • Platforms
  • Loot blocks
